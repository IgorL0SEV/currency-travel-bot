# План проекта VPd05 — API-валюта

## Цель

Telegram-бот «мини-кошелёк путешественника»: поездки с валютной парой,
курс из внешнего API, баланс в двух валютах, расходы, история, SQLite.
Публичный репозиторий `currency-travel-bot`.

## Предусловия

- Python 3.10+; проверено на 3.12.
- Аккаунт Telegram и бот, созданный в `@BotFather`.
- Ключ exchangerate.host (бесплатный тариф) — для основного провайдера.
- Доступ в интернет к `api.exchangerate.host` или `open.er-api.com`.

## Runbook: запуск на другой машине

```powershell
cd D:\python-projects
git clone https://github.com/IgorL0SEV/currency-travel-bot.git
cd currency-travel-bot
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# заполнить TELEGRAM_BOT_TOKEN и CURRENCY_API_KEY

```

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
.\venv\Scripts\python.exe demo.py
```

## Риски и заметки

- **Лимит 100 запросов/мес.** Курс кэшируется и хранится в поездке; расход
  виден в `/status`. Резервный open.er-api.com не тратит лимит основного.
- **Ключ exchangerate.host не активирован мгновенно.** При ошибке ключа
  бот предлагает ручной курс и резервный источник.
- **Курс зафиксирован на поездку.** Это защищает баланс от «прыжков».
  Изменение курса пересчитывает домашний баланс от валюты поездки.
- **Округление.** Валюта поездки округляется до копеек; домашний баланс
  уменьшается на стоимость расхода, поэтому начальная сумма остаётся ровной.
- **Состояние диалога в памяти.** Перезапуск прерывает незавершённый шаг,
  но не теряет поездки и расходы.
- **Секрет в git.** `.env` в `.gitignore`; перед публикацией — `git ls-files`
  и проверка истории на токен/ключ.
- **Курс сервиса — ориентировочный.** Это не курс покупки/продажи банка.
- **Материалы курса не публикуются.** Теория изложена своими словами,
  код написан самостоятельно.
